# 可可的书 · 线上画册工具

把可可的画做成**可预览、可筛选、可手机打印、可线上策展**的双语艺术画册。风格对齐 `可可画册.pptx`：A4 横版、大幅作品、英文斜体策展标题 + 中文标题 + 孩子口述故事 + 可选策展解析。

## 文件
- `index.html` — 主程序（双击即可打开，手机也能用，无需服务器）
- `album.json` — 布布老师维护的「真相源」（最终入选作品 + 故事 + 策展文案）
- `demo_curation_import.json` — 5 幅可可原画的策展示例（含图 + 标题 + 解析），可直接导入体验

## 解决了什么问题
- **iPhone HEIC**：客户端自动转 JPG（依赖 heic2any CDN，需联网；离线请发给我转）。
- **照片光线**：默认开启「自动修正光线」，用 canvas 自适应调整亮度/对比度/饱和度，让原画更鲜亮。
- **不喜欢的作品**：点「忽略」后不进打印版，不留失败墙。
- **风格统一**：打印页采用 A4 横版、大幅作品图、双语标题、克制中性底，和现有 PPT 画册一致。
- **线上策展**：英文策展标题 + 中文策展解析**不再在线上手动填写**——改由布布老师（我）按统一 prompt 自动生成，你只需把图发我。线上「🔍 展厅」只展示已生成的策展版。

## 日常怎么用（家长）
1. 打开 `index.html`（手机/电脑都行）。
2. 点 **➕ 加新作品** → 从手机相册选可可的画（或直接拍照）。支持 HEIC，会自动转 JPG 并修正光线。
3. 拿手机给可可看每一张：
   - 她喜欢 → 点 **❤️ 收进书里**，写下**她讲的故事**。
   - 她不喜欢 → 点 **不要**（不进书，不留失败墙）。
4. 点 **🔍 线上展厅** → 看大图 + 已生成策展文案（若布布老师已生成）+ 孩子故事。
5. 点 **🖨 打印这本书** → 选 **横版 A4**（一幅一页）或 **小册子**（一页两幅 · 对折成书），只印「收进书里」的作品 + 她的故事。
6. 数据自动存在本机浏览器；也可 **⬇ 备份** JSON，或 **⬆ 导入** 我给的策展版。

## 和布布老师怎么配合（标题/策展都交给我自动生成）
- **需要策展文案**：把图发给我，我按统一 prompt（`从策展的角度来看这幅画，但不要过于抽象`）返回 `英文标题 + 中文标题建议 + 策展解析`。你不必在线上填框——我会把带文案的 JSON 给你，**⬆ 导入**即可在「线上展厅」看到。
- **想最终打印稿**：把「备份」导出的 JSON 发我，我烘焙进 `album.json` 并产出统一风格的文件（双语标题 + 解析 + 她的故事）。
- **已有 PPT 画册风格基准**：已解包 `可可画册.pptx` 提取配色（奶油纸色、藏青标题、暖橘点缀）、字体（Calibri/PingFang）、A4 横版尺寸。

## 设计护栏（来自可可的特质）
- 她是**主编**：只收她认可/满意的；不喜欢的忽略，不批判、不留"失败墙"。
- 故事**不必匹配画面**：画只是故事入口，照录她口述的原话。
- 认字从**她口述的词**里挑，不考"画里有什么"。
- 打印版只含入选作品，给她"完成一本书"的闭合感。
- 策展解析是**大人视角的注释**，不进入"可可的书版"打印页，避免给她考核感。

## 打印小贴士
- 手机点打印会唤起系统打印/存 PDF；已经通过 `@page size: A4 landscape` 锁定横向，通常无需再手动调方向。
- 小册子模式打印后，沿中间对折，左边两页朝外即成小书。
- 若打印机只支持单面，小册子可先打印奇数页再翻面打印偶数页；家用简单做法：直接当"两幅一页的风琴折"也行。
- 目前小册子是「一页两幅」的简易对折版，不是严格骑马订页码排序；如需正式装订成册，可导出 JSON 给我，我用 python-pptx 生成精确排序的 PPTX。
